# Pustakam — Refactoring & Bug-Fix Register

> **Status:** Analysis only. **No code has been changed.** Review before any work begins.
> **Branch:** `master` (working tree clean at time of review).
> **Architecture (fixed constraint):** This is and stays a **KMM** project — shared Kotlin for data/domain, **native SwiftUI + Swift for the iOS UI**, native Jetpack Compose + ViewModels for Android. No shared/Compose-Multiplatform UI is proposed; the iOS UI stays hand-written Swift.
> **Scope:** `shared` (commonMain / androidMain / iosMain), `androidApp` (Compose), `iosApp` (SwiftUI).
> **Date:** 2026-06-25

## How to read this

Each row is a single issue: its current state, the proposed fix (aligned with standard best practices), the affected platform(s), a severity, and a rough effort.

**Severity:** 🔴 Critical · 🟠 High · 🟡 Medium · 🟢 Low
**Effort:** S (hours) · M (1–2 days) · L (multi-day) · XL (structural)

## Top 5 to fix first

1. **Auth is bypassed end-to-end** — `isAuthenticated` is hardcoded `true`, both apps skip the real start-destination check, and logout never clears state. *(B1, B2, D1)*
2. **Server sync is disabled** — every remote call in `NoteRepository`'s decision logic is commented out, so the app is local-DB only. *(B3)*
3. **Dev server URL + token logging are hardcoded on** — release ship blockers. *(F1, E1)*
4. **DI builds two repository instances** — auth state and notes state live in different objects. *(A1)*
5. **Rich-text formatting is half-wired** — model, DB column and toolbars exist, but spans are never saved or rendered. *(C1)*

## Suggested sequencing

A recommendation, not a commitment — we'll turn the agreed items into a file-by-file plan.

1. **Stop-the-bleeding (config & auth):** F1, B1, B2, D1, E1 — right backend, real auth, no token logs. (Mostly S, high impact.)
2. **Fix the DI instance split:** A1 (+D2) — one repository instance so auth and notes state agree.
3. **Data correctness:** B4, B6, B7, B8, B10, B11 — DAO transactions, status mapping, token capture, dead SQL.
4. **Finish the new features:** C1 (rich-text persistence), then decide C2 (tag sync); C3 cleanup.
5. **Turn sync on:** B3 — offline-first note sync (needs the A6/B5 prefs fix first).
6. **Stabilize the shared contract (keep native UI):** A2, A3, A4, A5 — inject `ApiCallClient`, centralize auth/token, share plain Kotlin use-cases. iOS UI stays native Swift.
7. **Hardening & polish:** F3, F4, F6, F9, E2–E6.
